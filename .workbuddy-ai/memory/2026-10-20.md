## Key findings (for future UI work)
- **P0 — brand blue contrast.** `#1591dc` with white text = 3.43:1 (fails AA). Same hex
  as text on white = 3.43; on `#e9f5fc` = 3.10; on Cloud Card `#ebf0f8` = 3.00.
  (Correction: `.chip-blue` was already using `--info` at 5.17:1 — it was never broken.)
  Hover `#0e7abf` = 4.61 (passes). Proposal: split into brand-500 `#1591dc` (graphics
  only) / brand-600 `#0b6fa8` (text + CTA fill, 5.45) / brand-700 `#0a6295` (hover).
- **P0 — type scale.** `@theme` declares 12/16/23/33/44/72 but the UI uses 125 arbitrary
  `text-[Npx]` declarations across 13 sizes (10px×19, 11px×36, 13px×41, 15px×20, rest ×1).
  10px legal text in footer at 4.28:1. Proposal: 8-step ladder, floor 12px except caps labels.
- **P1 — radius aliasing.** `--radius-lg/-xl/-2xl` all = 16px (globals.css:355–362);
  332 `rounded-*` declarations, 3 visual values. Proposal: surface 16 / control 10 / capsule.
- **P1 — two button systems.** `ui/button.tsx` (cva, rounded-full, h-9, shadow — violates
  spec) still imported by 2 files vs `ui/buttons.ts` (26 files). `sectionCtaBtn` is 36px on
  phones / 44px on desktop — inverted touch target.
- **P1 — hierarchy.** Page title 24/28px sits below the token "card heading" 33px; 51 `.eyebrow`
  call sites; review-queue bulk-email CTA renders as a pale chip beside filter chips.
- **P2 — landing hero** (`public-landing.tsx:605–615`) is a gradient band whose only child is
  an H1 duplicating the nav label.
- **P2 — staff mobile nav** = 7 tabs + ~150 lines of spacer/mirror geometry
  (`mobile-tab-bar.tsx`). Proposal: 4 tabs + More sheet; keep applicant 4-tab bar as-is.
- **P2 — colour overload.** Two greens (`--ok #1f7a3d` vs `--color-emerald-accent #34c771`,
  white-on 2.20) + colour-only `StageDot` beside the icon+colour pill grammar.
